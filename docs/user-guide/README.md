# Guide utilisateur — ENI Mail

Cette plateforme interne permet à tous les membres de l'ENI (étudiants,
enseignants, personnel administratif) d'échanger des messages de façon sécurisée.

## 1. Se connecter

1. Ouvrez votre navigateur sur l'adresse fournie par l'administration
   (par défaut `http://localhost:5173` en développement).
2. Saisissez votre **email ENI** et votre **mot de passe**.
3. Cliquez sur **Se connecter**.

En cas d'oubli, contactez l'administration (seul un administrateur peut
réinitialiser votre mot de passe).

## 2. Envoyer un message

1. Cliquez sur **Nouveau message** en haut à gauche.
2. Dans le champ **À**, commencez à taper :
   - un nom d'utilisateur ou une adresse email,
   - ou un nom de groupe (ex. `M1 GLBD`).
   Les suggestions apparaissent. Cliquez pour ajouter.
3. Saisissez l'**objet** puis le corps du message.
4. (Optionnel) Cliquez sur **Pièces jointes** pour ajouter un ou plusieurs fichiers.
   Taille maximale : **5 Mo par fichier**. Types autorisés : PDF, Office, images, zip, texte, CSV.
5. Cliquez sur **Envoyer** ou **Enregistrer brouillon** pour revenir plus tard.

## 3. Répondre ou transférer

Depuis la lecture d'un message :
- **Répondre** — à l'expéditeur uniquement.
- **Répondre à tous** — à l'expéditeur et à tous les destinataires (hors Cci).
- **Transférer** — envoyer le message à d'autres destinataires.

## 4. Gérer vos dossiers

- **Boîte de réception** — messages reçus non supprimés.
- **Envoyés** — messages que vous avez envoyés.
- **Brouillons** — messages en cours de rédaction, enregistrés automatiquement.
- **Corbeille** — messages supprimés (restaurables ou supprimables définitivement).

### Suppression

- Supprimer un message depuis la boîte de réception : il va dans votre corbeille **personnelle**. Les autres destinataires conservent leur copie.
- Supprimer définitivement depuis la corbeille : action irréversible pour vous.

### Marquer non lu

Depuis la lecture d'un message, cliquez sur **Non lu** pour le remettre comme non lu.

## 5. Rechercher

La barre de recherche en haut permet de trouver un message par :
- son **objet**,
- son **contenu**,
- le **nom de l'expéditeur**.

La recherche respecte vos droits : vous ne verrez jamais le message d'un autre
utilisateur auquel vous n'êtes pas associé.

## 6. Groupes de diffusion

L'onglet **Groupes** affiche la liste des groupes auxquels vous appartenez.

- Les **enseignants** peuvent créer des groupes et en gérer les membres.
- Les **étudiants** ne peuvent pas modifier les groupes.
- Les **administrateurs** ont tous les droits sur les groupes.

Pour envoyer un message à tous les membres, utilisez simplement le nom du
groupe dans le champ **À** d'un nouveau message. Les doublons sont supprimés
automatiquement si un utilisateur apparaît dans plusieurs groupes.

## 7. Mon profil

Cliquez sur votre avatar en bas de la barre latérale, puis **Mon profil** :
- Mettre à jour votre prénom, nom, filière, promotion.
- Changer votre mot de passe (il vous faudra saisir l'actuel).

## 8. Administration (admins uniquement)

Un administrateur dispose de l'onglet **Administration** :
- **Tableau de bord** : nombre d'utilisateurs par rôle, messages envoyés, groupes, etc.
- **Utilisateurs** : rechercher, filtrer, créer, désactiver ou réactiver un compte.

## 9. Sécurité et bonnes pratiques

- Verrouillez votre session en vous déconnectant depuis la barre latérale.
- Ne partagez jamais votre mot de passe.
- En cas de doute (message suspect, lien étrange), signalez-le à l'administration.
- Les messages sont conservés sur les serveurs de l'ENI.
